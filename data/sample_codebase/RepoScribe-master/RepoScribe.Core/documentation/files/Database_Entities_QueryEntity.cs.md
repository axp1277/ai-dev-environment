## Class: `QueryEntity`

An abstract class representing a query entity in the conversation history, containing details about each query and its responses.

**Purpose:** To store and manage query-related data within conversations

### Properties

  ### `Conversation`

  The conversation entity associated with this query entity

  ### `ConversationId`

  Unique identifier of the conversation associated with this query entity

  ### `HasResponse`

  Indicates whether this query entity has a response

  ### `IsBestResponse`

  Indicates whether this query entity is considered the best response among its related responses.

  ### `IsBot`

  Indicates whether this query entity represents a bot (true) or not (false)

  ### `IsQuery`

  Indicates whether this entity represents a query (true if it's a query, false otherwise)

  ### `IsResponse`

  Indicates whether this entity represents a response to another query

  ### `IsUser`

  Indicates whether this entity represents a user query

  ### `Provider`

  The name of the provider associated with this query entity

  ### `QueryId`

  Unique identifier for each query entity

  ### `QueryString`

  The raw query string entered by the user or bot

  ### `Response`

  The response message generated by the bot or retrieved from a provider.

  ### `Responses`

  A list of QueryEntity objects representing responses to this query

  ### `Source`

  The source of the query entity

  ### `TimeStamp`

  The date and time when this query entity was created or last updated.
