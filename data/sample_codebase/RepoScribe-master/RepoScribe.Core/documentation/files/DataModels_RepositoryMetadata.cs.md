## Class: `RepositoryMetadata`

Represents metadata for a GitHub repository, including its URL, author, readme content, and list of files.

**Purpose:** Stores and manages essential information about a GitHub repository

### Properties

  ### `Author`

  The author of the repository

  ### `Files`

  A list of FileMetadata objects representing all files in the repository.

  ### `Readme`

  The content of the README file for this repository.

  ### `Url`

  The URL of the repository
