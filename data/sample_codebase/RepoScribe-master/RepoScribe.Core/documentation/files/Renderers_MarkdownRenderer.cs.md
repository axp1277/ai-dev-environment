## Class: `MarkdownRenderer`

A class responsible for rendering various content items into Markdown format.

**Purpose:** Provides a centralized way to convert different types of content (code, images, PDFs, repositories) into Markdown for display.

### Methods

  ### `Render`

  Renders a ContentItem as Markdown string based on its type and optionally applies a template.

  **Parameters:**
  - `contentItem`: The content item to render
  - `template`: Optional template to apply to the rendered content

  **Returns:** Markdown string representation of the content item
