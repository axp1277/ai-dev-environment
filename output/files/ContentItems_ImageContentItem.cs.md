## Class: `ImageContentItem`

Represents an image content item with metadata and binary data.

**Purpose:** Stores and manages image-related content within the application.

### Methods

  ### `Ingest`

  Implements image ingestion logic for the current ImageContentItem instance.

  ### `SaveAsync`

  Saves the current instance of ImageContentItem asynchronously to both LocalDatabaseService and ChromaDbService.

### Properties

  ### `ImageData`

  Stores the binary data of the image

  ### `ImageMetadata`

  Represents metadata associated with an image content item
