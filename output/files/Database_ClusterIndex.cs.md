## Class: `ClusterIndex`

Represents a cluster index containing cluster ID, unique identifier, and list of member embeddings.

**Purpose:** Used to manage and reference clusters within the system

### Properties

  ### `ClusterId`

  Unique identifier for the cluster

  ### `ClusterIndexId`

  Unique identifier for this cluster index

  ### `MemberEmbeddings`

  A list of unique identifiers (GUIDs) representing member embeddings associated with this cluster index.
