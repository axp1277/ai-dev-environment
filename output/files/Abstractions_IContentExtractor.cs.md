## Class: `IContentExtractor`

Defines an interface for extracting content items from a given string input.

**Purpose:** Provides a standard way to extract structured data from unstructured strings.

### Methods

  ### `CanExtract`

  Checks if the given input can be extracted as content.

  **Parameters:**
  - `input`: The string to check for extraction

  ### `ExtractContent`

  Extracts content from a given string input.

  **Parameters:**
  - `input`: The string containing the content to extract
