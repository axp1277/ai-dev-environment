## Class: `Metadata`

Represents metadata for a file or document, including path, owner, modification details, size, language, and content.

**Purpose:** Stores and provides access to essential information about files

### Properties

  ### `Content`

  The content of the metadata as a string

  ### `Language`

  The primary language used in the content

  ### `LastModified`

  The date and time when this metadata was last modified.

  ### `Owner`

  The owner of the metadata resource

  ### `Path`

  The file path of this metadata

  ### `SizeMB`

  The size of the metadata in megabytes
