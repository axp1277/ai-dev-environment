## Class: `MarkdownDocument`

A class representing a Markdown document composed of multiple MarkdownContent sections.

**Purpose:** Used to build and manage complex Markdown documents

### Methods

  ### `AddContent`

  Appends the provided MarkdownContent to the internal list of contents.

  **Parameters:**
  - `content`: The MarkdownContent to add

  ### `ToString`

  Converts the MarkdownDocument to a string by concatenating all its contents.

### Fields

  ### `_contents`

  Stores the list of MarkdownContent items that make up this document
